## Why this exists

Anti-cheat work is not "find the file and delete it." Modern FPS cheats ship as subscriptions,
live in hardware (DMA cards, controller emulators), or never touch the target process at all
(computer-vision aim, external input injection). The durable counter is a **defense-in-depth
stack**:

1. **Host signals** — what is loaded, what is plugged in, what is signed, what is a known-vulnerable driver.
2. **Static signals** — YARA / packing / import traits on loaders and user-mode components.
3. **Behavioral signals** — server-side telemetry: aim kinematics, recoil regularity, reaction times.
4. **Economic / account signals** — boosting, deranking, smurfing, HWID ban evasion, account sharing.
5. **Intelligence** — what the cheat market is shipping this week ([cheat-intel](https://github.com/NetVar1337/cheat-intel)).

This repo is the *detection* half of that stack. It is written from the defender's side:
everything here is a way to **observe, score, and explain** anomalous behavior.

## Quick start

The detector dependencies are `detections/requirements.txt`. The sample files are generated, not shipped, because `data/` is gitignored.

```bash
cd detections
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_fixture.py
```

That writes `data/scores.csv` and `docs/fixture-results.md`. Read
[`docs/investigation-SYNTHETIC.md`](docs/investigation-SYNTHETIC.md) next. It uses
the measured scores, including the case where a high-skill human outranks a recoil
script on the composite.

The SQL in `sql/kpi_queries.sql` is PostgreSQL. The three headline questions run
without it:

```bash
python sql/sqlite_headlines.py
```

## Design notes

- **Every detector is a named, single-purpose feature.** Scores are explainable: an analyst should be able to tell a player why they were flagged, and a reviewer should be able to argue with a specific number.
- **Baselines are per-cohort.** Mouse and controller players do not produce the same kinematics. Scoring against a pooled baseline produces false positives.
- **Nothing here auto-bans.** Output is a prioritised review queue. The fixture run shows why: a high-skill human outranks a recoil script on the composite.

## Scope

Independent research. I do not work for a studio or an anti-cheat vendor. The fixture is synthetic and generated by `detections/run_fixture.py`. No game files, no bypasses, no operational cheat code. The YARA rules are triage sketches, not a detection feed.
